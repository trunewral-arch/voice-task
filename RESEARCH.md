## 🏆 1. Анализ лидеров рынка

| Продукт | Тип / Платформа | Главная фишка UX | Механика ввода | Как очищают речь | Главный минус / Боль пользователей |
|---|---|---|---|---|---|
| **Superlist (*Talk*)** | iOS, Android, Mac, Web | Голосовой разбор списка в канбан и задачи с контекстом | Длинное нажатие на `+` (Quick Create) или кнопка Talk | AI разбивает монолог на отдельные чек-листы и подзадачи | Задержка 3–6 сек на облачный AI; нет офлайна |
| **AudioPen** | PWA, Web, Android Widget | Превращение «каши из мыслей» в чистый структурированный текст | Push-to-Talk хоткей / плавающий виджет на Android | Удаление слов-паразитов, перефразирование, авто-форматирование | Не привязан к таск-трекерам «из коробки» (просто заметки) |
| **Voicenotes.com** | iOS, Android, Web, Watch | Разделение на митинги и одиночные «быстрые мысли» (memos) | 1 тап / виджет с блокировкой экрана | Транскрипция $\rightarrow$ AI-структурирование в заметку/список дел | Платная подписка (\$10/мес), облачная зависимость |
| **Oasis** | macOS, iOS, Windows | Системный Push-to-Talk поверх любых окон (HUD) | Удержание глобальной клавиши / кнопки | Мгновенная замена речи на отредактированный текст прямо в курсор | Только десктоп/iOS, нет нативной связки с канбанами |
| **Todoist (*Ramble*)** | Web, iOS, Android | NLP-распознавание дедлайнов, тегов и приоритетов (`p1`, `завтра`) | Голосовой ввод в строку быстрого добавления (Quick Add) | Regex + языковой парсер вырезает ключевые токены в свойства | Требует строгих ключевых слов, иначе путает текст задачи |

### Ключевые инсайты рынка:
1. **Люди ненавидят ждать:** Любая пауза больше 1.5 секунд между окончанием фразы и появлением карточки убивает ощущение «моментального сброса из головы».
2. **Push-to-Talk победил Tap-to-Record:** Когда кнопка зажата — пользователь говорит концентрированно. Когда отпустил — приложение сразу знает, что фраза закончена (не нужно ждать VAD/тишины 2 секунды).
3. **Безопасность подтверждения:** Приложения, которые сохраняют задачу втихую без превью, часто приводят к ошибкам в трекере. Окно подтверждения с крупной кнопкой `[OK]` дает 100% контроль.

## 🐙 2. Обзор топовых Open-Source репозиториев на GitHub

### 1. Голосовые PWA и Task-клиенты
* **[AzimPial/VoiceTask](https://github.com/AzimPial/VoiceTask)** *(Next.js, Dexie, Web Speech API)*  
  * *В чём фишка:* Автономный таск-менеджер на Web Speech API со связкой локальной базы данных Dexie (IndexedDB). Показывает, как красиво реализовать локальное офлайн-кэширование задач.
  * *Что забираем:* Модель хранения несинхронизированных задач в очереди с повторными попытками отправки.
* **[sudhanshuBHU/voice-controlled-todo-app](https://github.com/sudhanshuBHU/voice-controlled-todo-app)**  
  * *В чём фишка:* Быстрый перехват команд голосом («add task ...», «mark complete ...»).
  * *Что забираем:* Подход к очистке командных префиксов из тела задачи.
* **[chrono-node (GitHub / chrono-node)](https://github.com/wanasit/chrono-node)** *(~4.2k stars)*  
  * *В чём фишка:* Мощнейший JavaScript NLP-парсер дат на русском языке (`chrono.ru`). Распознает «завтра в 15:00», «в следующий понедельник», «через 2 часа».
  * *Что забираем:* Возможность в 1 строчку JS определять дату и дедлайн для TickTick, если пользователь упомянул день недели или время.

### 2. Репозитории по TickTick API
* **[Salen-Project/ticktick-mcp](https://github.com/Salen-Project/ticktick-mcp)** & **[dev-mirzabicer/ticktick-sdk](https://github.com/dev-mirzabicer/ticktick-sdk)**  
  * *В чём фишка:* Полная типизация REST API TickTick, структуры колонок (`columnId`), приоритетов (`0, 1, 3, 5`) и тегов.
  * *Что забираем:* Проверенные эндпоинты `POST /open/v1/task` и `GET /open/v1/project/{id}/column`.
* **[adrienjoly/telegram-scribe-bot](https://github.com/adrienjoly/telegram-scribe-bot)**  
  * *В чём фишка:* Бот для моментального сброса задач в TickTick из Telegram.
  * *Что забираем:* Форматирование описания задачи (`content`) с указанием метаданных (время надиктовки, теги, источник).

## 📱 3. Разбор UI/UX экрана и эргономики под один палец

Мы провели аудит текущего макета (8 кнопок сетки 2×4 + 3 нижних ползунка) по закону Фиттса (Fitts's Law) и анатомии хвата смартфона правой рукой:

┌──────────────────────────────────────────────┐  ▲

├──────────────────────────────────────────────┤  │ (Статус, сеть,
│  ИНФО-ПОЛОСА: "Готов к надиктовке"          │  ▼  живой транскрипт)
├──────────────────────────────────────────────┤
│  СЕТКА КАТЕГОРИЙ (PUSH-TO-TALK):             │
│                                              │
│  Левый палец (Бизнес/IT)   Правый (Быт/Жизнь)│
│  ┌────────────────────┐ ┌────────────────────┐│  [Тянуться дальше]
│  │ ⚡ 3-Вайб          │ │ 🍏 7-Тело          ││
│  └────────────────────┘ └────────────────────┘│
│  ┌────────────────────┐ ┌────────────────────┐│
│  │ 🎯 2-Лиды          │ │ 🛒 6-Купить        ││
│  └────────────────────┘ └────────────────────┘│

│  │ 🧪 1-Лабс          │ │ 🌹 5-Роза          ││

│  ┌────────────────────┐ ┌────────────────────┐│  ⭐ ИДЕАЛЬНАЯ ЗОНА

│  └────────────────────┘ └────────────────────┘│     (Мгновенный тап)

│  3 СЕГМЕНТНЫХ СЕЛЕКТОРА (Таблетки):          │
│  1. [ (0) Неотсорт | 1-Задача | 2-Сейчас | 3-Потом | 4-Заметка ]
│  2. [ (⚪ Без приор.) | 🟡 Жолтый | 🔴 Красный ]
│  3. [ (⚪ Без метки)  | 🔹 Мелкий | 🔷 Большой ]
└──────────────────────────────────────────────┘

### 💡 4 UX-улучшения для интерфейса:

1. **Жест «Свайп для отмены» (Swipe to Cancel из Telegram/WhatsApp):**
   * *Проблема:* Если пользователь случайно зажал кнопку или запнулся на первых словах, ему приходится отпускать палец, ждать карточку и жать «Отмена».
   * *Решение:* Если палец во время зажатия сдвигается вверх или влево больше чем на 40px, рамка кнопки вспыхивает красным, появляется значок урны 🗑️, а при отпускании запись просто сбрасывается без открытия модалки.

2. **Живой стриминг распознавания (Live Interim Wave):**
   * Пока палец удерживает кнопку, верхняя инфо-полоса превращается в пульсирующую волну и показывает промежуточный распознанный текст прямо в процессе говорения (`recognition.interimResults = true`). Пользователь сразу видит, что микрофон его слышит.

3. **Тактильный профиль (Haptic Feedback):**
   * Нажатие кнопки (`touchstart`): одиночный короткий импульс **40 мс**.
   * Отпускание кнопки (`touchend`): легкий щелчок **20 мс**.
   * Успешный разбор и показ модалки: двойной мягкий импульс **[30 мс, пауза 40 мс, 30 мс]**.
   * Свайп-отмена: протяжная вибрация **80 мс**.

4. **Двойной доступ к селекторам:**
   * Селекторы видны на главном экране (для предварительного выбора тапом), **НО** также дублируются прямо внутри окна подтверждения! Если при надиктовке захотелось сменить статус на `2-Сейчас` или поставить `🔴 Красный`, это делается в один клик прямо перед нажатием `[OK]`.

## 🗄️ 4. Анализ полей и структуры данных

Мы сопоставили выбранную структуру с лучшими мировыми практиками GTD (David Allen) и Agile/Kanban:

### А. 8 Проектов — почему это оптимум:
* Психологический закон Миллера ($7 \pm 2$) доказывает, что 8 категорий — это абсолютный предел кратковременной памяти человека, при котором не требуется прокрутка экрана.
* Разделение на 2 колонки (Левая = IT / Бизнес; Правая = Быт / Личное) четко разделяет рабочее и персональное мышление.

### Б. 5 Колонок — идеальный баланс статусов:
1. **`0-Неотсортирован` (Inbox):** Для быстрого сброса, когда некогда думать.
2. **`1-Задача` (Next Actions):** Сформулированные дела, готовые к выполнению на этой неделе.
3. **`2-Сейчас` (In Progress / Focus):** Жесткий фокус дня (максимум 2-3 задачи одновременно).
4. **`3-Потом` (Someday / Maybe):** Идеи, отложенные задачи без горящих сроков.
5. **`4-Заметка` (Reference):** Справочная информация, замеры, пароли, ссылки.

### В. Свойства задачи (Двойной маппинг в TickTick):
* **Приоритет:**
  * Устанавливаем тег в TickTick: `🏀красный` или `🥎жолтый`.
  * **И одновременно** выставляем нативный `priority` в TickTick API:
    * `🔴 Красный` ➔ `priority: 5` (High Priority в TickTick)
    * `🟡 Жолтый` ➔ `priority: 3` (Medium Priority в TickTick)
    * `⚪ Без приоритета` ➔ `priority: 0`
  * *В чём выгода:* Задача подсвечивается и в списке тегов, и в системных фильтрах TickTick («Сегодня», «Важные», «Матрица Эйзенхауэра»).
* **Размер задачи (Длительность):**
  * `🔹 Мелкий` ➔ тег `мелкий` (быстрые дела до 15-30 мин, правило 2 минут).
  * `🔷 Большой` ➔ тег `большой` (глубокая работа, требует от 1 часа).

## 🧠 5. Алгоритмы локального парсинга русской речи

Web Speech API на смартфонах Android передает распознанный текст через Google Speech Services. В русском языке есть специфика: числа могут приходить как цифрами («2»), так и словами («два»), а цвета и статусы склоняются по падежам и родам.

### Архитектура легковесного парсера:
```javascript
// Нормализатор русской речи для TickTick Voice PWA
const NLP_RULES = {
  columns: [
    { id: 0, name: "0-Неотсортирован", patterns: [/\b(ноль|0|неотсорт|вход|инбокс)\b/i] },
    { id: 1, name: "1-Задача",         patterns: [/\b(один|1|задач[аеу]|план)\b/i] },
    { id: 2, name: "2-Сейчас",         patterns: [/\b(два|2|сейчас|в работе|срочно делать)\b/i] },
    { id: 3, name: "3-Потом",          patterns: [/\b(три|3|потом|позже|когда-нибудь|отложи)\b/i] },
    { id: 4, name: "4-Заметка",        patterns: [/\b(четыре|4|заметк[аеу]|инфо|инфа|записка)\b/i] }
  ],
  priorities: [
    { tag: "🏀красный", priority: 5, patterns: [/\b(красн(ый|ая|ое|ую)|огонь|критично|срочно)\b/i] },
    { tag: "🥎жолтый",  priority: 3, patterns: [/\b(ж[ео]лт(ый|ая|ое|ую)|важн(о|ый|ая))\b/i] }
  ],
  sizes: [
    { tag: "мелкий",   patterns: [/\b(мелк(ий|ая|ое)|быстр(о|ый)|пятиминутка)\b/i] },
    { tag: "большой",  patterns: [/\b(больш(ой|ая|ое)|долг(о|ий)|проект)\b/i] }
  ],
  garbageWords: [
    /\b(запиши|добавь|пометь|напомни|короче|слушай|эээ|ну|так|в общем)\b/gi
  ]
};
```

### Принцип работы:
1. Регулярные выражения вычленяют триггеры колонки, цвета и размера.
2. Найденные служебные слова удаляются из строки.
3. Слова-паразиты (`эээ`, `короче`, `запиши`) отсекаются.
4. Оставшаяся фраза очищается от лишних пробелов, а первая буква автоматически становится заглавной.

## 🤖 6. Интеграция с Android на системном уровне

Чтобы приложение вызывалось так же быстро, как диктофон:

1. **PWA App Shortcuts (`manifest.json`):**
   * При долгом нажатии на иконку приложения на рабочем столе Android всплывает быстрое меню с прямым выбором топ-категорий:
     * 🛒 `Быстрая покупка`
     * 🌹 `Роза / Дом`
     * ⚡ `Вайб-кодинг`
     * 🍏 `Тело / Здоровье`
2. **Экран блокировки (Lock Screen) и Боковая кнопка:**
   * В Android 14+ PWA-ярлык можно вынести в угол экрана блокировки.
   * На телефонах Samsung / Xiaomi через настройки боковой кнопки (или бесплатную утилиту *Key Mapper*) двойное нажатие кнопки питания можно привязать к мгновенному открытию PWA.
3. **Standalone Fullscreen:**
   * `display: "standalone"`, скрытие адресной строки браузера, цвет шторки `#000000`, блокировка случайного зума через `touch-action: manipulation`.
