# План разработки (план2.md) — Мобильный голосовой пульт и синхронизация с Канбаном

> **Для исполнителя:** ОБЯЗАТЕЛЬНЫЙ НАВЫК: Используйте `superpowers:executing-plans` или пошаговую реализацию задач. Задачи содержат чекбоксы (`- [ ]`) для контроля прогресса.
> **Статус:** Реализовано и протестировано (версия v1.9.0). Все 34 unit/e2e теста пройдены.

**Цель:** Создать автономный легковесный мобильный HTML-пульт с 4 кнопками для голосового ввода задач на Android (с решением проблем обрыва связи, эхо и свайпов из `2_Voice_Task`) и связать его с нашим Канбаном через открытый облачный буфер `ntfy.sh` (с сохранением офлайн-очереди).

**Архитектура:** 
1. `voice.html` — легковесная автономная PWA/страница для Android.
2. `ntfy.sh` — нулевой по сложности транспортный буфер (открытый CORS, без аккаунтов и серверов).
3. `src/components/SyncButton.tsx` + `src/utils/remoteSync.ts` — приёмник задач в основном канбан-приложении на ПК.

---

## Глобальные ограничения и правила
* **Никаких собственных серверов:** работаем только в браузере (клиентский JS).
* **Офлайн-первичность:** надиктовка в походе без интернета должна надёжно сохраняться в память телефона (`localStorage`).
* **Непрерывный Push-to-Talk:** при паузах в речи Android не должен сбрасывать запись (наследуем проверенную логику `SpeechEngine` из `2_Voice_Task`).
* **Точное сопоставление 4 кнопок с папками Канбана:**
  1. `biz_inbox` ➔ Рабочее пространство `business`, папка «Входящие», колонка `0-Вход`.
  2. `pers_inbox` ➔ Рабочее пространство `personal`, папка «Входящие», колонка `0-Вход`.
  3. `pers_buy` ➔ Рабочее пространство `personal`, папка «Купить», колонка `0-Вход`.
  4. `biz_radar` ➔ Рабочее пространство `business`, папка «Радар», колонка `0-Вход`.

---

## Фокус проверки качества (Review Focus)
1. **Паузы при удержании кнопки:** пользователь замолчал на 2 секунды, думая над формулировкой — запись не прерывается, фраза не теряется.
2. **Отсутствие связи в лесу:** отправка в сеть падает с ошибкой — задача гарантированно падает в офлайн-очередь, счётчик очереди увеличивается на 1.
3. **Свайп отмены:** палец соскользнул или передумал — жест сдвига влево/вверх отменяет ввод без отправки.
4. **Безопасная дедупликация:** при повторной синхронизации задачи не должны дублироваться в канбане (проверка по уникальному ID задачи `local_xxx`).
5. **CORS и отклик:** запросы к буферу не вызывают ошибок в консоли браузера на Android и Windows.
