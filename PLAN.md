# Voice Task PWA — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Построить ультра-быстрое автономное PWA-приложение (в стиле Apple Dark Mode) для Android и десктопа для мгновенного голосового создания задач с авто-каталогизацией в TickTick через Open API.

**Architecture:** Одностраничное приложение (`index.html`) с модульной архитектурой на чистом ES6 JavaScript: Push-to-Talk на базе Web Speech API, локальный русскоязычный NLP-парсер параметров, тактильный движок Haptic Feedback, офлайн-очередь в `localStorage` и прямой REST-клиент к TickTick Open API.

**Tech Stack:** Vanilla JavaScript (ES6+), HTML5, Tailwind CSS / Custom CSS, Web Speech API (`webkitSpeechRecognition`), Web Vibration API, Web Audio API, Service Worker, TickTick REST API v1.

**Spec:** [`IDEA.md`](file:///j:/!!!-PROJECT-!!!/1-Delo/IDEA.md) и [`RESEARCH.md`](file:///j:/!!!-PROJECT-!!!/1-Delo/RESEARCH.md)

## Global Constraints

- **Zero-Latency Capture:** Никаких тяжелых серверных задержек; локальный парсинг и Web Speech API дают мгновенный отклик.
- **Apple Dark Mode Design:** Глубокий черный фон `#000000`, карточки `#1C1C1E`, скругление 16–20px, цветные акцентные полоски из `Voice_uchet`.
- **Эргономика под один палец:** Сетка 2×4 адаптирована под правую руку: самые частые бытовые кнопки внизу справа под большим пальцем (`4-Разное`, `5-Роза`, `6-Купить`, `7-Тело`).
- **Строгий контроль подтверждения:** Карточка подтверждения НЕ закрывается по таймеру; строго ждет явного тапа `[✅ OK]` или `[❌ Отмена]`.
- **Автосброс:** После отправки задачи сегментные переключатели мгновенно возвращаются в дефолт (`0-Вход`, `Обычный`, `Без метки`).
- **Свайп для отмены:** Сдвиг пальца во время записи влево/вверх на >40px сбрасывает запись без мусора.
- **Безопасность TickTick:** Токен `tp_...` хранится в `localStorage` браузера пользователя.

## Review Focus

1. **Мобильный Push-to-Talk:** Предотвращение паразитного скролла страницы и системных жестов при удержании кнопки (`touch-action: none`, `e.preventDefault()` с `{ passive: false }`).
2. **Чистота заголовка при парсинге:** Если пользователь сказал *"купить два жолтый мелкий чеснок в чижике"*, заголовок задачи в TickTick должен стать строго *"Чеснок в чижике"*, а параметры уйти в колонку `2-Сейчас`, тег `🥎жолтый` и тег `мелкий`.
3. **Двойной маппинг в TickTick:** Отправлять и текстовый тег (`🏀красный`, `🥎жолтый`), и нативное числовое поле `priority: 5` или `3`.
4. **Офлайн-надежность:** При отсутствии сети задача не теряется, а сохраняется в локальной очереди и улетает в TickTick сама при событии `online`.
5. **Корректные ID проектов и колонок:** Использовать точные существующие ID проектов пользователя в TickTick и автоматически находить/создавать нужные 5 колонок.
