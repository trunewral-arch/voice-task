## Реализованный функционал

- [x] **TickTick API Client & Project/Column Mapping Engine**
  - Подключение к TickTick REST API v1.
  - Синхронизация 8 категорий с точными ID проектов.
  - Канонические 5 колонок (`0-Вход`, `1-План`, `2-Сейчас`, `3-Потом`, `4-Инфо`) настроены во всех 8 проектах.
  - Двойной маппинг приоритетов (числовой `priority: 5|3|0` и теги `🏀красный`, `🥎жолтый`).
  - Маппинг размеров задач (`мелкий`, `большой`).
- [x] **Русскоязычный NLP-парсер задач и очистка речи**
  - Распознавание колонок, цветов (включая все падежи и букву «ё»: `жёлтый`, `красный`, `обычный`), размеров (`мелкий`, `большой`, `без размера`).
  - Хронологический приоритет: последняя произнесённая команда побеждает в реальном времени.
  - Трёхуровневая дедупликация повторов (`cleanRecognizedText` из `Voice_uchet`): устранение 1-грамм, N-грамм и суффиксного эхо.
  - Очистка паразитных слов и связок («надо», «нужно», «запиши», «короче»).
  - 17/17 unit-тестов парсера пройдены.
- [x] **Мобильный Push-to-Talk и жесты**
  - Сетка 2×4 адаптирована под управление большим пальцем правой руки.
  - Непрерывное прослушивание без обрыва на Android: если система прерывает сеанс из-за паузы в речи, recognition мгновенно перезапускается за 60 мс, пока палец удерживает кнопку.
  - Фиксация указателя (`setPointerCapture`) предотвращает срывы записи при микродвижениях пальца.
  - Защита от контекстного меню браузера (`contextmenu.preventDefault()`) и ложных кликов.
  - Свайп для отмены (>60px влево/вверх) со сменой индикации на корзину и тактильной отдачей.
  - Тактильный вибро-отклик (Web Vibration API) и звуковые сигналы (Web Audio API).
- [x] **Сегментные переключатели и карточка подтверждения**
  - 3 ряда интерактивных плашек: Колонка, Приоритет, Размер.
  - Живое автопереключение плашек прямо во время диктовки.
  - Модальное окно подтверждения перед отправкой: возможность поправить текст, сменить категорию или колонку.
  - Карточка не закрывается по таймеру — строго ожидает нажатия `[✅ Отправить (OK)]` или `[❌ Отмена]`.
  - Автосброс селекторов в дефолт (`0-Вход`, `Обычный`, `Без метки`) после создания задачи.
- [x] **Офлайн-очередь (Offline Task Queue)**
  - Автоматическое сохранение задач в `localStorage` при отсутствии интернета или ошибках сети.
  - Автосинхронизация при восстановлении соединения (`window.ononline`).
  - Счётчик задач в очереди в шапке приложения.
- [x] **PWA & Автономность**
  - Полноценный Web App Manifest с режимом `display: "standalone"` (скрывает верхнюю адресную строку браузера при установке на рабочий стол).
  - Сгенерированы и подключены иконки PNG 192×192, 512×512 и `apple-touch-icon.png`.
  - Кнопка «Установить» в шапке (перехват `beforeinstallprompt`).
  - Service Worker (`sw.js`, `voicetask-v6`) с Network-First стратегией и автоматической очисткой старых кэшей.
- [x] **Безопасность**
  - Токен TickTick хранится исключительно локально в `localStorage` браузера пользователя.
  - В открытом репозитории на GitHub ключей и токенов нет (проверено скриптами безопасности).
- [x] **GitHub Pages & CI/CD**
  - Код опубликован в ветке `main` репозитория `https://github.com/trunewral-arch/voice-task`.
  - Сайт автоматически публикуется и доступен по адресу `https://trunewral-arch.github.io/voice-task/`.

## Предложения и идеи для развития (на следующий этап)

1. **История последних созданных задач:**
   - Быстрый список (последние 5–10 задач) с возможностью удалить задачу из TickTick в один тап при случайном создании.
2. **Распознавание дедлайнов и дат:**
   - Голосовые команды типа «завтра в 15:00», «в пятницу», «через 2 часа» с автоматической простановкой `dueDate` в TickTick API.
3. **PWA Shortcuts / Быстрые действия с иконки:**
   - Вызов создания задачи в конкретную категорию по долгому тапу на иконку приложения на рабочем столе телефона.
4. **Режим пакетной надиктовки (несколько задач подряд):**
   - Возможность сказать «купить хлеб, купить молоко, купить масло» и создать сразу 3 отдельные задачи в один клик.
5. **Поддержка подзадач (Checklist Items):**
   - Если надиктован список через слово «пункт» или «и», сохранять как чеклист внутри задачи TickTick.
